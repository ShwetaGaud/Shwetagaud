# Online Code Editor

A web-based online code editor developed using Django and Ace Editor. It allows users to write, edit, and execute code in multiple programming languages through a browser-based interface.

## Features

- Multi-language code execution
- Syntax highlighting
- Code autocomplete and snippets
- Real-time error handling
- User input and output display
- File upload
- Code download
- Automatic code saving
- Light and dark editor themes
- WebSocket-based code updates
- User authentication and logout

## Supported Languages

- Python
- Java
- JavaScript
- C++
- PHP

## Technologies Used

- Python
- Django
- Ace Editor
- HTML
- CSS
- JavaScript
- Bootstrap

## Project Overview

The Online Code Editor provides an interactive environment for writing and executing programs directly through a web browser. Users can select a programming language, write code, provide input, run the program, and view the output.
